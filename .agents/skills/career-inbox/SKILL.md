# Входящие по поиску работы

Прочитай `career/WORKFLOW.md` и актуальные условия. Сначала установи охват: папка HR, конкретные рекрутеры, даты кампании. Перед чтением и отправкой сверяй адресата. Не считай весь аккаунт разрешённым из-за открытого Telegram. Не выводи пароли, OTP или токены.

Различай автоответ, просьбу заполнить форму, технический вопрос, отказ, назначенную встречу и оффер. На известные вопросы отвечай из профиля, сохраняй условия net-дохода и удалёнки. Не превращай согласие самостоятельно платить налоги в безусловное согласие на любую gross-сумму. Не обещай дату, статус ИП или согласие на новое использование фото без основания.

Ответы отправляй только в действующей авторизации; дополнительных разрешений для уже разрешённого не нужно. При неизвестном обязательном факте поставь этот чат в исключения и продолжай остальные. Подтверди отправку по UI и сохрани результат без увеличения числа откликов. При завершении укажи точный охват проверки и незавершённое.

## Входящие и черновики в дашборде

Начни с `python3 career/scripts/career_memory.py context`. Уточни, какие диалоги входят в задачу. Из корня проекта команда `python3 manage.py inbox` показывает входящие, требующие действия. Правила уже выделяют явные автоответы, отказы, вопросы, тестовые, приглашения и офферы. Для неоднозначного сообщения сверяй полный диалог и исправляй тип, срочность, следующий шаг и согласованную дату в карточке. Оффер и приглашение не считаются назначенной встречей.

Чтобы подготовить черновик:

1. Для Gmail используй `python3 manage.py inbox-context ID` для конкретной записи. Проверь `reply_to`, последнее письмо и `reply_to_latest`. Если уже ответили, адресат пуст или изменился, сначала открой оригинальный диалог. Для HH используй ссылку из карточки, проверь работодателя и автора последнего входящего, дочитай историю в разрешённом чате. Видимые в дашборде фрагменты HH могут содержать исходящие сообщения.
2. Для содержательного ответа используй существующую роль `career-editor` или её правила. Сверь нужные записи profile/evidence, выбери язык диалога, составь несколько естественных предложений. Известные условия учти без повторного вопроса. Неизвестные условия уточни у адресата, а неподтверждённые даты оставь на согласование. Предложи 2–3 слота только после проверки доступности и укажи часовой пояс.
3. Сохрани текст в карточке или через `python3 manage.py inbox-draft ID --file -` (stdin). Сверь текст и получателя с оригиналом. Это локальный черновик. Отдельное разрешение нужно для фактической отправки.
