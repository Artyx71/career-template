# Проверка фактов CV

Прочитай профиль/evidence и нужные исходники из указанных владельцем репозиториев. Для работы с Git проверяй точный хэш и путь изменения; рассматривай все доступные refs, различая укороченную историю, переносы, merge, неподтверждённые алиасы и отсутствие авторского вклада. Пакет/технология в зависимостях не доказывает реализацию.

Выход — карта утверждений по [схеме](../../../career/references/preflight.md): текст, evidence-id, область опыта/замера и ограничения. Новое доказательство и новая формулировка — разные вещи. Для code_checked достаточно собственного технического изменения, но бизнес-uplift требует измерений. Не присваивай метрики из референсов и не превращай веточный прототип в запущенную коммерческую функцию.

При противоречии дат сохрани действующее решение пользователя и явно оставь unresolved; не изобретай причину. Правки канонического профиля/evidence выполняй только по новым подтверждениям с источниками, не из сгенерированного CV. Если вопрос только о чтении, ничего не редактируй и не отправляй.
