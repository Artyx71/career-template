# Факты кандидата

Источники: `career/profile.json`, `evidence.json` и `WORKFLOW.md`. Разделяй подтверждение пользователя, проверку кода и предположение. У даты, навыка и метрики должен быть понятный источник; повтор прежнего AI-текста не является новым подтверждением.

Сохраняй коммерческий и личный опыт раздельно. Общий frontend-стаж не равен React-стажу; Node/инструменты личных проектов не превращаются в коммерческий backend. Назови границы каждого измерения. Приблизительное значение помечай как приблизительное, неизвестное — оставляй неизвестным.

Обновляй факты только по новой информации с источником и датой. Не переспрашивай уже подтверждённое. Неизвестные обязательные факты собирай в одну очередь, не вставляй маркеры уточнения в отправляемое резюме. Не меняй реальную причину увольнения на удобную без подтверждения.
