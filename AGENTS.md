# Карьерный трекер

Дашборд запускается локально. Команды запуска и настройки описаны в README.md.

Используйте локальный профиль и подтверждения как источник фактов, SQLite и журналы как источник статусов. Для подбора сверяйте формат работы, зарплату, обязательные требования и дубли. Отмечайте отклик отправленным после подтверждения площадкой.

Для сообщений и анкет используйте подтверждённые факты и сверяйте адресата. Внешние отклики, сообщения и отправку анкет выполняйте только с действующим разрешением пользователя. По умолчанию сохраняйте черновики.

Храните личные данные, резюме, переписку, браузерные сессии, ключи и базы вне Git. Для кода запустите `python3 -m unittest discover -s tests`.

Для карьерной задачи начните с [флоу поиска](career/WORKFLOW.md). Проектные роли в `.codex/agents/` и навыки в `.agents/skills/` используют данные владельца текущей копии.

Для разработки применяйте Ponytail **full**. Переиспользуйте существующие решения и ограничивайте изменения задачей. Сохраняйте проверки и обработку ошибок. Для браузерных проверок, поиска HH и чтения выбранной папки Telegram Web используйте локальный Playwright с Chromium по инструкции README.
